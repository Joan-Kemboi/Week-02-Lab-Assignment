# GRC102 - Security Policy Development Lifecycle

## Overview

This repository contains my Week 2 Practical Laboratory submission for GRC102 – Developing Security Policies and Procedures.

The assignment presents a Security Policy Development Lifecycle framework for NexusTech Solutions, designed to improve governance, compliance, accountability, and operational security.

## Project Objectives

- Establish a Security Policy Hierarchy
- Define Policies, Standards, Procedures, and Guidelines
- Develop an Acceptable Use Policy (AUP)
- Create a User Access Request Procedure
- Design a Security Communication and Training Plan
- Develop a Policy Review and Maintenance Process
- Align governance with ISO/IEC 27001, ISO/IEC 27002, NIST CSF 2.0, and SOC 2 principles

## Deliverables

### Evidence Bundle 1
- Security Policy Hierarchy
- Hierarchy Diagram
- Statement Classification Analysis

### Evidence Bundle 2
- Acceptable Use Policy (AUP)

### Evidence Bundle 3
- User Access Request Procedure

### Evidence Bundle 4
